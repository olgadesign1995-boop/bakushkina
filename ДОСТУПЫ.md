# Постоянные доступы: GitHub + Vercel

Одноразовые коды входа больше не используем — они живут 10–15 минут и умирают
в паузе между сообщениями. Вместо них — два постоянных токена, которые
работают месяцами.

**Токены не присылать в чат.** Их нужно положить в файл и прикрепить файл
к сообщению — это безопасно и переживает перезапуск сессии.

---

## 1. Токен GitHub (2 минуты)

1. Откройте **https://github.com/settings/tokens/new**
   (Профиль → Settings → Developer settings → Personal access tokens → Tokens (classic))
2. **Note** — впишите: `arena-portfolio`
3. **Expiration** — выберите `90 days` (или `No expiration`, если не хотите повторять)
4. **Select scopes** — поставьте **одну** галочку: **`repo`**
   (внутри автоматически отметятся все подпункты — так и нужно)
5. Внизу — **Generate token**
6. Скопируйте строку вида `ghp_XXXXXXXXXXXX` — она показывается **один раз**

---

## 2. Токен Vercel (1 минута)

1. Откройте **https://vercel.com/account/settings/tokens**
2. **Create Token**
3. **Token Name** — впишите: `arena-portfolio`
4. **Scope** — выберите свой аккаунт (`olgadesign199...`)
5. **Expiration** — `No Expiration` или `90 days`
6. **Create** → скопируйте строку вида `vercel_XXXXXXXX`

---

## 3. Как передать их мне

Создайте у себя на компьютере обычный текстовый файл **`tokens.txt`**
и впишите ровно две строки:

```
GITHUB_TOKEN=ghp_сюда_первый_токен
VERCEL_TOKEN=vercel_сюда_второй_токен
```

Прикрепите этот файл к следующему сообщению (скрепка) и напишите «токены».

Я сразу:
- перенесу их в `/home/user/.secrets/tokens.env` (папка в `.gitignore`, в репозиторий не попадёт);
- удалю исходный файл из `uploads/`;
- проверю оба доступа и продолжу работу.

## Что это даёт

- Я сам пушу коммиты в GitHub — вам не нужно ничего скачивать и загружать.
- Я вижу настройки проекта Vercel через API и могу починить причину 404.
- Я настрою процесс: мои правки → ветка `dev` → **Preview**-деплой →
  вы жмёте **⋯ → Promote to Production**.
- Токены переживают перезапуск сессии — повторять эту процедуру не придётся.

## Безопасность

- Оба токена отзываются одной кнопкой на тех же страницах, где создавались.
- Область GitHub-токена ограничена репозиториями (`repo`), доступа к оплате
  и удалению аккаунта у него нет.
- В код и в репозиторий токены не попадают: `/.secrets/` внесена в `.gitignore`.
- Когда сайт будет опубликован — отзовите оба, я напомню.
