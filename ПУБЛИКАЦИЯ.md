# Как опубликовать сайт: GitHub → Vercel

Инструкция «куда нажимать». Всё, что можно было сделать за вас, уже сделано:
проект собран, проверен, закоммичен. Осталось создать репозиторий и подключить Vercel —
это действия в веб-интерфейсах, доступа к которым у меня нет.

**Время: ~15 минут.** Секреты в чат не присылайте — они вводятся только в Vercel.

---

## Почему архив, а не автоматическая загрузка

Я проверил песочницу: учётных записей GitHub и Vercel в ней нет, CLI обоих сервисов
отвечают «No existing credentials found». Войти за вас я не могу, а просить прислать
логин или токен в чат — нельзя (это то же правило, по которому я просил отозвать токен
Figma). Поэтому я сделал максимум со своей стороны: собрал, проверил и упаковал проект
в готовый архив. Вам остаются только клики в двух интерфейсах.

---

## Шаг 1. Создать репозиторий на GitHub (3 минуты)

1. Откройте **github.com** → кнопка **+** справа вверху → **New repository**.
2. **Repository name:** `portfolio` (или любое другое имя).
3. **Visibility:** можно **Private** — Vercel работает и с приватными.
4. ⚠️ **Ничего не добавляйте**: галочки «Add a README», «Add .gitignore», «Choose a license» — **снять все**. Репозиторий должен быть пустым.
5. Нажмите **Create repository**.
6. На открывшейся странице скопируйте адрес вида `https://github.com/ВАШ-ЛОГИН/portfolio.git`.

**Пришлите мне этот адрес** — я подключу его к проекту и подготовлю всё к отправке.

---

## Шаг 2. Загрузить код (архив уже готов)

**Скачайте `portfolio-site.zip`** из рабочей папки — в нём весь сайт, 531 файл,
включая все картинки. Распакуйте на компьютере.

### Путь А (самый простой) — загрузка через браузер, без установки программ
1. На странице только что созданного пустого репозитория нажмите
   **uploading an existing file** (ссылка в тексте) — или откройте
   `https://github.com/ВАШ-ЛОГИН/portfolio/upload/main`.
2. Перетащите в окно **всё содержимое** распакованной папки
   (именно содержимое: `src`, `public`, `package.json` и остальное, а не саму папку).
3. Внизу нажмите **Commit changes**.

⚠️ У браузерной загрузки лимит — 100 файлов за раз, а в проекте их 531 (почти все —
картинки). Поэтому грузите в 2 захода: сначала всё, кроме папки `public`,
затем отдельно `public`. Либо используйте путь Б — он проще для такого объёма.

### Путь Б (рекомендую при таком количестве файлов) — GitHub Desktop
1. Скачайте и установите **desktop.github.com**, войдите в свой аккаунт GitHub.
2. **File → Add local repository** → укажите распакованную папку.
3. Если предложит «create a repository» — согласитесь.
4. Внизу слева впишите описание коммита → **Commit to main**.
5. Вверху нажмите **Publish repository** → снимите галочку «Keep this code private»,
   если хотите публичный → **Publish**.

При этом пути шаг 1 можно пропустить: GitHub Desktop создаст репозиторий сам.

### Путь В — терминал, если привыкли к командной строке
```
cd путь/к/распакованной/папке
git init
git add .
git commit -m "Портфолио"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/portfolio.git
git push -u origin main
```
GitHub попросит логин и **Personal Access Token** вместо пароля:
**Settings → Developer settings → Personal access tokens → Tokens (classic) →
Generate new token**, права — только `repo`.

## Шаг 3. Подключить Vercel (5 минут)

1. Откройте **vercel.com** → **Sign Up** / **Log In** → войдите **через GitHub**.
2. На главной панели нажмите **Add New…** → **Project**.
3. В списке репозиториев найдите `portfolio` → **Import**.
   Если репозитория нет в списке: **Adjust GitHub App Permissions** → дайте доступ.
4. Vercel сам определит Next.js. **Ничего менять не нужно:**
   - Framework Preset: `Next.js`
   - Build Command: по умолчанию
   - Output Directory: по умолчанию
5. Нажмите **Deploy** и подождите 1–2 минуты.
6. Готово — Vercel покажет адрес вида `portfolio-xxxx.vercel.app`.

**Про ветку.** Проект подготовлен в ветке `main` — это ветка по умолчанию и для GitHub,
и для Vercel. Первый же деплой сразу станет **Production**, никаких дополнительных
настроек и никакого merge не требуется. Сайт откроется на адресе вида
`ваш-проект.vercel.app` — это и есть тестовый домен Vercel.

**Кнопка «Deploy to Production».** После импорта она нажимается сама при первом
деплое. В дальнейшем: **Deployments** → у нужного деплоя меню **⋯** →
**Promote to Production**.

---

## Шаг 4. Включить индексацию (2 минуты)

Сейчас сайт намеренно закрыт от поисковиков — так задумано, пока нет постоянного адреса.

1. Vercel → ваш проект → **Settings** → **Environment Variables**.
2. **Key:** `NEXT_PUBLIC_SITE_URL`
   **Value:** полный адрес сайта, например `https://portfolio-xxxx.vercel.app`
   (или ваш домен, если подключите).
   **Environment:** отметьте **Production**.
3. **Save**.
4. Перейдите на вкладку **Deployments** → у верхнего деплоя меню **⋯** → **Redeploy**.
5. Проверьте: `ваш-адрес/robots.txt` — должно быть `Allow: /`, а не `Disallow: /`.

---

## Шаг 5. Свой домен (по желанию, 5 минут + ожидание DNS)

1. Vercel → проект → **Settings** → **Domains** → введите домен → **Add**.
2. Vercel покажет, какие записи прописать у регистратора домена:
   - **Поддомен** (например `olga.example.com`): запись **CNAME** → `cname.vercel-dns.com`
   - **Корневой домен** (`example.com`): запись **A** → `76.76.21.21`, плюс **CNAME** для `www` → `cname.vercel-dns.com`
3. Пропишите записи в личном кабинете регистратора, где куплен домен.
4. Подождите от 10 минут до нескольких часов. HTTPS Vercel выпустит сам.
5. После подключения домена **обновите** `NEXT_PUBLIC_SITE_URL` на новый адрес → **Redeploy**.

## Шаг 6. Приём заявок в Telegram (10 минут)

Сейчас форма честно отвечает «Приём заявок ещё не подключён» и показывает прямые
контакты — ложного «успешно отправлено» не бывает. Чтобы заявки приходили в Telegram:

### 6.1. Создать бота
1. В Telegram найдите **@BotFather** — обязательно с **синей галочкой**.
2. Отправьте `/newbot`.
3. Введите имя бота (любое, например `Заявки с портфолио`).
4. Введите username — должен заканчиваться на `bot`, например `olga_portfolio_bot`.
5. BotFather пришлёт **токен** вида `1234567890:AAxxxxxxxx`.
   ⚠️ **Не присылайте его мне.** Он идёт только в Vercel.

### 6.2. Узнать свой chat_id
1. Найдите своего бота по username, откройте, нажмите **Start**.
2. Напишите ему любое сообщение, например «привет».
3. Откройте в браузере (подставив свой токен):
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите в тексте `"chat":{"id":123456789` — число после `"id":` и есть ваш **chat_id**.

### 6.3. Внести в Vercel
Settings → **Environment Variables**, добавьте две переменные для **Production**:

| Key | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | число из предыдущего шага |

Затем **Deployments** → **⋯** → **Redeploy**.

### 6.4. Проверить
Откройте сайт, заполните форму, отправьте. Сообщение должно прийти вам в Telegram.
Если не пришло — напишите мне, что показала форма, разберёмся.
