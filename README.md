# Портфолио — Ольга Бакушкина

Сайт-портфолио графического дизайнера. Next.js + TypeScript.

## Быстрый старт

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки |
| `npm run build` | production-сборка |
| `npm run start` | запуск собранного сайта |
| `npm run lint` | проверка кода |
| `npm run media` | пересборка медиа из `uploads/` (AVIF/WebP/JPG, MP4/WebM, постеры) |
| `node scripts/check-links.mjs` | проверка якорей, изображений и контактов на запущенном сайте |

## Структура

```
src/
  app/            маршруты, метаданные, robots, sitemap, OG-картинка
    api/lead/     приём заявок формы (Telegram)
  components/     Hero, Works, ProjectSection, ContactForm и др.
  data/
    projects.ts        ← ЕДИНЫЙ ИСТОЧНИК контента проектов
    media-manifest.json  размеры и пути медиа (генерируется)
  lib/            site.ts (метаданные), media.ts (работа с манифестом)
public/media/     оптимизированные изображения — идут в репозиторий
uploads/          исходники в оригинале — в репозиторий НЕ идут
docs/             бриф, структура, концепции, контент
```

## Как добавить или изменить проект

1. Положите исходники в `uploads/` с именами `<проект>-cover.jpg`, `<проект>-01.jpg`, `<проект>-loop-*.mp4`.
2. Выполните `npm run media`.
3. Добавьте запись в массив `projects` в `src/data/projects.ts`.
4. `npm run build` — готово. Якорь секции берётся из поля `id`.

## Переменные окружения

Задаются в Vercel → Settings → Environment Variables. В код и репозиторий не попадают.

| Переменная | Назначение |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | публичный адрес сайта. Без неё сайт закрыт от индексации |
| `TELEGRAM_BOT_TOKEN` | токен бота для приёма заявок |
| `TELEGRAM_CHAT_ID` | получатель заявок |

Без токенов форма честно отвечает ошибкой конфигурации и показывает прямые контакты —
ложного «успешно отправлено» не бывает.
