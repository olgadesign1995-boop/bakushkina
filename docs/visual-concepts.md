# Фаза 3. Визуальные концепции первого экрана

Три варианта. Все построены на реальной материи работ (77 выгруженных изображений),
на светлой базе, без 3D-абстракций, прелоадеров и захвата скролла.
Ожидается выбор пользователя.

---

## Что даёт материал

Разбор палитры выгруженных работ показал четыре чётко разделённых мира:

| Проект | Доминанта | Характер |
|---|---|---|
| «Домашний» | тёплый розовый `#c09b9b` → малиновый | эмоция, ирония, персонаж |
| Ecozavr | шалфейно-зелёный `#cbd4c6` | природа, чистота, продукт |
| АльфаСтрахование | песочно-бежевый `#dec9ac` + красный | корпоративность, объём |
| Презентации | глубокий фиолетово-синий `#4f2bb6` | данные, структура |

**Вывод для дизайна:** у сайта не должно быть собственного кричащего цвета —
он обязан быть нейтральным холстом, иначе подерётся с работами. Цвет на странице
приходит из самих проектов. Это же снимает анти-референс «градиенты конфликтуют
с персонажной графикой».

**Базовая палитра сайта (общая для всех концепций):**
- Фон: тёплый белый `#faf9f7` (не стерильный `#fff` — работы на нём дышат)
- Текст: почти-чёрный `#16151a`
- Второстепенный текст: `#6b6a73`
- Линии: `#e4e2dd`
- Акцент интерфейса: берётся у активного проекта (розовый / зелёный / красный / синий)

**Типографика:** Manrope для заголовков (геометричный гротеск, не спорит с иллюстрацией),
Inter для текста. Обе локальные, уже стоят.

## Концепция 1. «Полка и лента» ⭐ рекомендую

**Метафора:** два полюса из утверждённого заголовка — *упаковка на полке* и *ролик в ленте*.
Физический предмет слева, экранный формат справа.

**Что видно в первую секунду:** крупный заголовок, а по бокам — реальные работы в двух
разных «носителях»: слева бутылка Ecozavr стоит как на полке (вертикальный кадр,
мягкая тень, ощущение предмета), справа вертикальный кадр 9:16 с маскотом «Домашнего»
как пост в ленте. Между ними — имя и роль.

**Интеракция:** при скролле два полюса медленно расходятся, освобождая место работам —
буквально «раскрывается» портфолио. Движение маленькое (20–40 px), исключительно по вертикали.

**Технология:** CSS Grid + `transform` на скролле через IntersectionObserver.
Без WebGL, без библиотек анимации в первом экране.

**Fallback:** при `prefers-reduced-motion` — статичная композиция, смысл не теряется.
На мобильном полюса становятся двумя карточками в ряд под заголовком, высота ~55vh.

**Риск непонимания:** низкий. Композиция читается как «дизайнер, работающий и в печати,
и в цифре» — ровно то, что нужно донести.

**Почему рекомендую:** это единственная концепция, где визуальная идея **дословно
пересказывает заголовок**. HR за 5 секунд видит диапазон, арт-директор видит качество
предметной съёмки и персонажа одновременно. И она честная — сделана из настоящих работ,
а не из декора.

## Концепция 2. «Контактный лист»

**Метафора:** контрольный лист печати / раскадровка — сетка кадров, из которой
дизайнер отбирает финал. Отсылка к реальному этапу вашей работы: перебор вариантов и отбор.

**Что видно в первую секунду:** плотная сетка 5×3 маленьких кадров из всех проектов,
поверх — заголовок. Один кадр «выбран»: он крупнее, подсвечен, с тонкой рамкой,
и раз в несколько секунд выбор перескакивает на другой кадр.

**Интеракция:** наведение на любой кадр делает его выбранным; клик ведёт к проекту.
Автоперебор останавливается при взаимодействии.

**Технология:** CSS Grid + небольшой JS-таймер. WebGL не нужен.

**Fallback:** без движения — просто сетка с одним выделенным кадром.
На мобильном сетка 3×3 из лучших кадров.

**Риск:** средний. Плотная сетка может прочитаться как «плитка без описаний» —
прямой анти-референс. Снимается тем, что это только первый экран, а ниже идут
развёрнутые кейсы. Но риск есть.

## Концепция 3. «Один герой, много сцен»

**Метафора:** ваш ключевой навык — консистентность персонажа. Один и тот же маскот
в разных ситуациях, кадр за кадром.

**Что видно в первую секунду:** крупный кадр «Дамы-мелодрамы» или кота Альфы,
который плавно сменяется другой сценой с тем же персонажем — как перелистывание поз.
Заголовок статичен поверх.

**Интеракция:** смена кадров по таймеру (3–4 с) с мягким кроссфейдом; точки-переключатели.

**Технология:** CSS-кроссфейд между предзагруженными изображениями.

**Fallback:** один статичный кадр.

**Риск: высокий, и я обязан предупредить.** Эта концепция противоречит утверждённому
позиционированию: она ставит персонажей на первое место, а вы прямо просили,
чтобы во главе был **графический дизайн полного цикла**, а персонажи — сильной
стороной внутри него. Первый экран с маскотом прочитается как «иллюстратор»,
и вакансии графического дизайнера пройдут мимо. Показываю вариант, потому что
визуально он самый обаятельный, но рекомендовать не могу.

|---|---|---|---|

| Риск непонимания | низкий | средний | высокий |
| Конфликт с анти-референсами | нет | возможен («плитка») | нет |
| Соответствие позиционированию | полное | частичное | противоречит |
| Сложность | низкая | низкая | низкая |

**Рекомендация: концепция 1.**

## Общее для всех концепций

- Никакого WebGL в первом экране. `three`/`@react-three/fiber` останутся в проекте
  и могут быть применены точечно ниже по странице, если появится осмысленная задача.
- Высота hero ≤ 70vh на десктопе, ≤ 60vh на мобильном — край первого проекта виден сразу.
- Изображения: `<picture>` с AVIF/WebP/JPG, явные `width`/`height` из манифеста
  (нулевой layout shift), первое изображение — `priority`, остальные ленивые.
- Все анимации отключаются при `prefers-reduced-motion`.
- Обложка Ecozavr будет заменена: сейчас в роли обложки коллаж-сетка,
  для карточки нужен одиночный предметный кадр.
