# Спецификация медиафайлов

Короткий ответ: **отдавайте максимальное качество, которое у вас есть, — размеры и форматы я приведу сам.**
Ниже точные цифры на случай, если хотите экспортировать сразу правильно.

---

## Главное правило

Не уменьшайте и не сжимайте файлы вручную. Присылайте оригиналы: я прогоню их скриптом
`scripts/prepare-media.mjs`, который сам сделает WebP/AVIF нужных размеров, постеры для видео
и MP4/WebM. Ваша задача — качество и осмысленные имена, остальное автоматизируется.

---

## 1. Изображения

### Какие форматы отдавать
| Отдавайте | Не отдавайте |
|---|---|
| PNG, JPG высокого качества, TIFF | Скриншоты из мессенджеров |
| PDF (для печатных макетов, одностраничные) | Пережатые картинки из соцсетей |
| SVG (логотипы, векторные знаки) | Файлы шириной меньше 1200 px |

Итоговые форматы на сайте (сделаю сам): **AVIF + WebP** с JPG-запасом.

### Размеры по назначению

| Назначение | Соотношение | Отдавать не меньше | Итог на сайте |
|---|---|---|---|
| **Обложка проекта** (карточка в сетке) | 4:3 | 2000 × 1500 | 1200 / 800 / 480 px по ширине |
| **Крупный кадр внутри проекта** | 16:9 или 3:2 | 2400 × 1350 | 1600 / 1200 / 800 |
| **Вертикальный кадр** (сторис, этикетка, упаковка стоя) | 4:5 или 9:16 | 1600 × 2000 | 1080 / 720 / 480 |
| **Квадрат** (пост, стикер, иконка персонажа) | 1:1 | 1600 × 1600 | 1080 / 720 / 480 |
| **Портрет для блока «О себе»** | 4:5 | 1600 × 2000 | 800 / 560 / 400 |
| **Логотип / знак** | — | SVG или PNG 1024 px с прозрачностью | SVG как есть |

**Вес оригинала:** до 20 МБ на файл — нормально. Итоговые версии на сайте будут 80–250 КБ.

### Что важно в самих кадрах
- Обложка проекта должна читаться в маленьком размере — на мобильном она шириной ~330 px.
- Не вставляйте подписи и заголовки прямо в картинку: текст на сайте будет отдельно, живым шрифтом (иначе он не читается на телефоне и не индексируется).
- Персонажа на обложке лучше давать крупно, без больших пустых полей — обрежется.

## 2. Видео и GIF

**Да, видео размещается прямо на странице** — без ухода на YouTube или другой сервис
(это был ваш анти-референс). Работает так: постер-картинка → нажатие → воспроизведение на месте.

### ⚠️ GIF отдавать не нужно
GIF в 5–20 раз тяжелее видео при худшем качестве: 10-секундная анимация в GIF весит 8–15 МБ,
та же в MP4 — 400–900 КБ. **Присылайте видеофайл, даже если хотите «эффект гифки»** —
короткий беззвучный автоповтор я сделаю из видео. Если GIF единственный исходник — тоже
присылайте, сконвертирую, но качество будет хуже оригинала.

### Что отдавать
| Параметр | Значение |
|---|---|
| Формат | **MP4 (H.264)** — как экспортирует CapCut по умолчанию |
| Разрешение | 1920 × 1080 для горизонтали, 1080 × 1920 для вертикали. Больше — можно, меньше 1280 — нежелательно |
| Частота кадров | 25 или 30 fps |
| Битрейт | не экономьте, 8–20 Мбит/с; итог сожму сам |
| Длина | **фрагменты по 10–30 секунд.** Целый ролик на 3 минуты HR не досмотрит |
| Звук | оставляйте, если он есть — я сделаю две версии: с озвучкой и беззвучный автоповтор |

### Два режима видео на сайте
1. **Автоповтор без звука** («живая гифка») — короткие петли 3–8 секунд: персонаж в движении,
   вращение упаковки, перелистывание макета. Стартует сам, беззвучно, гаснет при `prefers-reduced-motion`.
2. **Ролик с воспроизведением** — фрагмент 15–30 секунд со звуком. Показывается постером,
   играет по нажатию, не грузится, пока не нажали.

Итоговые форматы (сделаю сам): **MP4 (H.264)** + **WebM (VP9)** + постер WebP/AVIF.

## 3. Имена файлов

Кладите всё в `uploads/` и называйте так, чтобы я понял, куда это встанет:

```
ecozavr-cover.jpg              — обложка проекта
ecozavr-01-etiketka.jpg        — кадры по порядку
ecozavr-02-polka.jpg
ecozavr-03-marketplace.png
domashniy-cover.jpg
domashniy-01-personazh.png
domashniy-loop-poza.mp4        — короткая петля
insurance-01-scene.jpg
insurance-rolik-fragment.mp4   — фрагмент со звуком
portret.jpg
logo.svg
```

Правила: латиница, дефисы вместо пробелов, префикс = проект, номер = порядок показа.
Если имена будут другие — не страшно, просто напишите в сообщении, что где.

## 4. Минимальный комплект, чтобы страница ожила

| Проект | Минимум | Хорошо |
|---|---|---|
| Ecozavr | обложка + 3 кадра | + фото на полке, инфографика для маркетплейса, POS |
| «Домашний» | обложка + 3 кадра персонажа | + петля с движением, стикерпак, обложки соцсетей |
| Страховая (обезличенно) | обложка + 2 кадра | + фрагмент ролика 15–30 с |
| Финансовая (NDA) | обложка + 1–2 кадра | + фрагмент презентации |
| А. Коркунов | 1–2 кадра упаковки | — |
| О себе | портрет | — |

**Итого минимум: ~13 изображений. Комфортно: 20–25 изображений + 2–4 видео.**

## 5. Как передать файлы

Прикрепите к сообщению в чате — они попадут в `uploads/`.
Можно частями: например, сначала Ecozavr, я его соберу и покажу, дальше остальные.
Так вы увидите результат раньше и поймёте, стоит ли что-то доснять.

**Если файлов много и они тяжёлые:** присылайте по 5–8 за раз.

---

## 6. Что делает скрипт `scripts/prepare-media.mjs`

Запускаю я, вручную ничего делать не нужно:

1. Читает оригиналы из `uploads/`.
2. Генерирует AVIF + WebP в 3–4 размерах для каждого изображения.
3. Из видео делает MP4 (H.264) + WebM (VP9), беззвучную петлю и постер-кадр.
4. Раскладывает в `public/media/<проект>/` и пишет манифест с размерами,
   чтобы страница не «прыгала» при загрузке (защита от layout shift).
